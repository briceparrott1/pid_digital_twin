Added density-based stop logic: should_stop_cutting now also checks ink_density (new in cost_map.py). Sparse segments (density < min_ink_density=0.008) stop immediately regardless of size, killing wasted near-empty calls. Dense segments (density >= dense_density_threshold=0.03) use a lower floor (dense_min_dim=400, dense_min_area=250000) instead of the normal 800/1e6, letting the busiest network clusters cut one level deeper. Thresholds calibrated from run_4's real 19-segment density distribution.
